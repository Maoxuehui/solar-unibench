# ESSD Submission Figure Set

Copernicus/ESSD-formatted versions of the core benchmark figures, generated by
`scripts/plots/plot_essd_figures.py` (one mandatory parameter block owns every size,
color, and dimension — no magic numbers in the plotting layers).

| File | Content | Source data |
|---|---|---|
| `fig1_crossover_frontier_waterfall` | (a) hierarchical crossover margin χ per dataset vs deep-model mean/best; (b) governance waterfall (LightGBM probe) | `results_e9_cross_dataset.csv`, `results_e9_waterfall.csv` |
| `fig2_benchmark_skill_heatmap` | E8 daytime Skill (MAE \| RMSE), 7 models × 4 datasets × 3 native horizons (CrossViViT v2; DLinear excluded from display) | `figures/results/e8_summary.csv` |
| `fig3_benchmark_horizon_lines` | Skill vs native horizon per dataset — the persistence-crossover view | `e8_summary.csv` |
| `fig4_data_defects` | (a) inter-step gap distributions; (b) column-wise missingness with Honest-NaN modality colors | `defect_summary.csv` + standardized packages |
| `fig5_optflow_quality` | (a) context/extrapolated/observed/uncertainty at K=1; (b) PSNR + SSIM vs lead K | `results_e4_optflow.csv` path (re-evaluated) |

## Formatting contract

- Arial 8.5 pt everywhere (single size); panel tags 9.5 pt bold
- 180 mm double-column width; per-figure heights derived from the panel rows
- Wong/Okabe-Ito discrete palette; RdBu_r only for the diverging skill heatmap
- No plot titles; concise academic panel labels; LaTeX math notation on all
  axes (no snake_case code variables)
- White canvas, major grid #E5E5E5 @ 0.3 only, no minor grids
- Dual export: vector PDF (fonttype 42, editable text) + 300 dpi PNG

## Regenerate

```bash
conda run -n solar_uni python scripts/plots/plot_essd_figures.py
```

The equivalent dev/working versions of the same figures live in
`figures_full/` and `figures/results/` (README-level docs); this folder is the
submission snapshot.
